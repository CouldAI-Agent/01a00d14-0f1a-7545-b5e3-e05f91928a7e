# Aurb - دستیار صوتی هوشمند

Aurb یک برنامه چت و مکالمه صوتی پیشرفته با هوش مصنوعی است که برای مکالمات طبیعی و روان به زبان فارسی طراحی شده است. این برنامه بدون نیاز به فشردن دکمه یا انتظار، همیشه در حال گوش دادن و پاسخ دادن به شماست.

## ویژگی‌ها
- **مکالمه روان و طبیعی**: هوش مصنوعی با لحن و گویش شبیه به انسان (رسمی و محاوره‌ای) صحبت می‌کند.
- **بدون دکمه و کلید**: مکالمه کاملاً پیوسته و بدون نیاز به تعامل لمسی است. هوش مصنوعی همیشه گوش می‌دهد.
- **رابط کاربری جادویی**: یک گوی شیشه‌ای سه‌بعدی با امواج رنگارنگ درون آن که با حجم و ریتم صدا تعامل دارد.
- **صداهای حرفه‌ای**: پشتیبانی از صداهای شبیه‌سازی شده گویندگان و دوبلورهای مشهور ایرانی.

## نحوه اجرا
برای اجرای برنامه در محیط توسعه Flutter:
```bash
flutter run
```

## ساختار پروژه
- `lib/main.dart`: فایل اصلی برنامه شامل رابط کاربری گوی سه‌بعدی و انیمیشن‌های تعاملی.

## درباره CouldAI
این برنامه با استفاده از [CouldAI](https://could.ai) ایجاد شده است؛ یک سازنده برنامه هوش مصنوعی برای برنامه‌های چند پلتفرمی که پرامپت‌ها را به برنامه‌های واقعی و بومی iOS، Android، Web و Desktop تبدیل می‌کند. CouldAI از طریق عوامل هوش مصنوعی خودکار، معماری، ساخت، آزمایش، استقرار و تکرار برنامه‌های آماده تولید را انجام می‌دهد.
